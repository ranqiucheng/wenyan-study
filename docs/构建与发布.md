# 构建与发布

## 环境准备

每次构建前先加载环境变量：

```powershell
. 'D:\dev\env.ps1'
```

## Windows 版

```powershell
cd 'D:\学习\DScoding项目测试\wenyan\app'
flutter build windows --debug     # 产物：build\windows\x64\runner\Debug\wenyan.exe
flutter build windows --release   # 产物：build\windows\x64\runner\Release\
```

## Windows 便携包

Debug 版依赖同目录 DLL 与 `data/`，不能只拷 exe。发布时打包：

```powershell
$build = 'D:\学习\DScoding项目测试\wenyan\app\build\windows\x64\runner\Debug'
$dst = 'D:\学习\DScoding项目测试\wenyan\release\文言研习-Windows-v0.1.0'
robocopy $build $dst /E /XF *.pdb
Compress-Archive -Path $dst -DestinationPath "$dst.zip" -Force
```

当前产物：`release/文言研习-Windows-v0.1.3-导入.zip`（30.7 MB，解压即用，含老师端）。

> Windows 数据目录：`%APPDATA%\wenyan`（cards.json / wrongs.json）。

## Android APK

### debug 包（可直接在工作区构建）

```powershell
cd 'D:\学习\DScoding项目测试\wenyan\app'
flutter build apk --debug
# 产物：build\app\outputs\flutter-apk\app-debug.apk
```

### release 包（必须走 ASCII + NTFS 路径）

当前工程位于 `D:\学习\DScoding项目测试\wenyan\app`，而 **D 盘是 exFAT**：AOT 编译器（gen_snapshot）读不了中文路径，release 构建会报 `Unable to read file ... app.dill` / `AOT snapshotter exited with code 255`；exFAT 也不支持 junction。

临时构建流程：

```powershell
$src = 'D:\学习\DScoding项目测试\wenyan\app'
$dst = 'A:\dev\wenyan-app'     # A 盘是 NTFS，路径纯英文
robocopy $src $dst /E /XD build .dart_tool .idea
cd $dst
flutter build apk --release
# 产物：A:\dev\wenyan-app\build\app\outputs\flutter-apk\app-release.apk
Copy-Item "$dst\build\app\outputs\flutter-apk\app-release.apk" `
  'D:\学习\DScoding项目测试\wenyan\release\文言研习-v0.1.0-测试版.apk' -Force
Remove-Item $dst -Recurse -Force
```

> 不要用 junction 把工作区目录映射到 ASCII 路径：D 盘是 exFAT，不支持。

### 签名说明

- 当前 release 包使用 Flutter 模板默认的 **debug keystore** 签名（证书 `CN=Android Debug`），只适合内部测试。
- 正式对外分享前，需要生成自己的 keystore 并在 `android/app/build.gradle.kts` 配置 `signingConfigs`；**更换签名后无法覆盖安装旧包**（需先卸载）。
- keystore 与口令要离线备份两处。

## 分发与安装

### 推荐分发方式

| 渠道 | 体验 | 说明 |
|---|---|---|
| QQ 群文件 | 较好，通常可直接调起安装器 | 首选；需允许 QQ「安装未知应用」 |
| 微信文件 | 需 3 步（微信不允许直接安装 APK） | 附上 `release/安装说明.png` 和 `微信发送文案.txt` |
| 公网下载链接 | 浏览器下载后直接安装 | 需要静态托管；适合人数较多的场景 |

### 随包附带的材料

| 文件 | 用途 |
|---|---|
| `release/文言研习-v0.1.0-测试版.apk` | 安装包 |
| `release/安装说明.png` | 可直接发群里的安装图文（QQ/微信/各品牌设置） |
| `release/QQ群发文案.txt` | QQ 群发送时直接复制 |
| `release/微信发送文案.txt` | 微信发送时直接复制 |

> 注意：微信/QQ 能不能“直接安装”由腾讯和手机厂商决定，App 本身无法控制；QQ 通常比微信松，但不同版本/机型仍有差异。iPhone 不越狱、不上架 App Store 无法安装。

## Windows 导出内容包

老师端「导出」使用 Windows 系统另存为对话框，可自选保存位置和文件名；实现方式为调用 PowerShell 的 WinForms `SaveFileDialog`（无需插件）。

## 手机安装

1. 把 APK 发到手机（微信文件传输助手 / 数据线 / 网盘均可）
2. 点击安装，若提示“禁止安装未知来源应用”，在系统设置里允许
3. 安装后打开，应用名显示为「文言研习」

## 已知限制

- **D 盘 exFAT**：git 无 ownership、junction 不可用、release AOT 不支持中文路径 → release 必须走上面的 ASCII NTFS 临时目录。
- **Chrome 缺失**：只影响 `flutter build web`，不影响 Android/Windows。
- **iOS**：第一版不做。
