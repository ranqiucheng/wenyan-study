# 老师端使用说明（M3 第一版）

## 打开方式

1. 双击 `release/文言研习-Windows-v0.1.9/wenyan.exe`
2. 在首页右上角点 **「老师端」按钮**（学校图标 + 文字，在搜索图标左边）
3. 进入「文言研习 · 老师端」，左侧两个入口：**篇目** / **导出**
4. 点右上角「学生端」返回

> 目前只有 Windows 版有老师模式；手机端是学生界面。

## 能做什么

### 新增内容

- **新增篇目**：篇目列表页 →「新增篇目」→ 填篇名/作者/出处/册次 → 自动打开编辑器
- **新增句子**：编辑器右上「新增句子」→ 填原文与译文
- **新增词条**：每句右侧「加词条」图标 → 填词（必须出现在本句）、词性、释义
- 新增词条会自动进入**刷题题库**（当前题目由词条自动生成）

### 自定义题目与排序

- **出题**：每句右侧「问号」图标 → 填加点词/正确释义/3 个干扰项/解析，保存后随内容包导出，学生刷题时会出现。
- **排序**：篇目列表每篇右侧 ↑ ↓ 调整顺序，导出内容包时按该顺序排列。
- **筛选**：列表上方「全部 / 待校对 / 已校对」。

### 批量校对与快捷键

- 篇目列表「全部标记已校对」：一键把全部篇目标记为已校对
- 编辑器快捷键：`Ctrl+Enter` 切换已校对、`Ctrl+P` 预览、`Ctrl+K` 课堂、`Esc` 返回

### 篇目与编辑

- 篇目列表显示：已校对 / 待校对、修改处数、句子数
- 点开一篇 → 逐句卡片：
  - 点句中**词条按钮** → 修改词性 / 释义
  - 点译文右侧的 **文A 图标** → 修改整句译文
  - 右上角开关 → 标记「已校对」
  - 眼睛图标 → 预览学生端阅读效果

修改会**即时保存到本机**，不需要手动保存按钮。

### 导出内容包

1. 左侧切到「导出」
2. 点「导出 .wyc」
3. 弹出 Windows 的**另存为对话框**：自己选保存位置和文件名
4. 保存后显示文件路径，可直接复制/打开文件夹

> 导出位置完全由你决定，不再固定写到 AppData。

内容包内含 `manifest.json`（版本、数量、SHA-256）和全部篇目 JSON，结构与手机端一致。

## 课堂模式（投屏）

在篇目编辑器右上角点 **投影/课堂图标** 进入：

- 全屏大字，当前句高亮显示
- `←` `→` 或 `↑` `↓` 翻句
- `空格` 显示/隐藏本句全部注释
- `T` 显示/隐藏整句译文
- 点句中的词 → 弹出释义卡片
- `Esc` 退出

适合投影仪/大屏讲课；建议 F11 全屏后再进入课堂模式。

## 数据存放位置

| 内容 | 路径 |
|---|---|
| 老师修改 | `%APPDATA%\wenyan\teacher_edits.json` |
| 导出内容包 | 导出时你选择的位置 |
| 学生学习记录 | `%APPDATA%\wenyan\cards.json`、`wrongs.json` |

## 建议测试流程

1. 打开《劝学》→ 点「已」改释义为「停止（老师改）」→ 返回列表看「修改 1 处」
2. 点开同一篇点眼睛预览，确认学生端看到的是修改后的内容
3. 切到「导出」→ 导出 → 打开文件夹确认 `.wyc` 已生成
4. 关闭程序重开，确认修改还在
