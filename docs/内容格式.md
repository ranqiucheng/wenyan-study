# 内容格式 v1（M1）

> 当前实现位于 `app/assets/content/`，与未来的内容包 `.wyc` 使用同一套 JSON 结构。
> 样例：3 篇（《劝学》《师说》《赤壁赋》），共 12 句。

## 目录结构

```
assets/content/
├── index.json          # 篇目索引
└── lessons/
    ├── quanxue.json
    ├── shishuo.json
    └── chibifu.json
```

## index.json

```json
{
  "schemaVersion": 1,
  "contentVersion": "2026.10-m1",
  "lessons": [
    { "id": "quanxue", "title": "劝学", "author": "荀子", "volume": "必修上册", "file": "lessons/quanxue.json" }
  ]
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| schemaVersion | int | 格式版本，当前 1 |
| contentVersion | string | 内容版本，用于内容包升级判断 |
| lessons[].file | string | 相对 `assets/content/` 的路径 |

## lesson

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | 全局唯一，如 `quanxue` |
| title / author / source / volume | string | 是 | 篇名、作者、出处、册次 |
| tags | string[] | 否 | 如 `课标`、`议论` |
| reviewed | bool | 是 | 是否已校对；学生端只展示已校对内容 |
| summary | string | 否 | 一句话内容简介 |
| sentences | Sentence[] | 是 | 按 `order` 升序 |

## sentence

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | 篇内唯一，如 `quanxue-001` |
| order | int | 是 | 排序 |
| text | string | 是 | 原文句子 |
| translation | string | 是 | 整句译文 |
| tokens | Token[] | 是 | 需要注释的词，按在句中出现的顺序排列 |

## token

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| surface | string | 是 | 词形，必须能在 `text` 中按顺序匹配到 |
| pos | string | 否 | 词性，如 `动词`、`介词` |
| gloss | string | 是 | 释义 |

## 规则

1. `sentence.text` 必须**按 tokens 顺序**包含全部 `surface`；UI 按顺序查找，找不到的词会被跳过（数据错误）。
2. 每个句子必须有译文；每个 token 必须有释义。
3. `reviewed=false` 的篇目不进入学生端（老师端可编辑）。
4. `id` 稳定不变；修改内容时保留 id，便于后续内容包做增量合并。
5. 未来内容包 `.wyc` 的结构与本目录一致（ZIP + manifest.json + lessons/ + words/ + questions/ + assets/）。
