# 项目结构

## 顶层

```text
wenyan/
├─ app/                 Flutter 应用（Android 学生端 + Windows 老师端）
├─ assets/              见 app/assets
├─ content/             内容生产规范与新增篇目元数据（不参与打包）
├─ docs/                方案、格式、教程、截图、发布说明
├─ tools/               Python：内容校验 / `.wyc` 打包
├─ release/             本地构建产物（Git 忽略，用 GitHub Releases 分发）
├─ README.md
├─ LICENSE
└─ .gitignore
```

## app/

```text
app/
├─ lib/
│  ├─ data/             内容仓库、训练题库仓库
│  ├─ models/           Lesson / Token / WordCard / CustomQuestion / Training
│  ├─ pages/            阅读、复习、刷题、训练、我的、老师端、课堂、导入
│  ├─ services/         存储、SRS、老师编辑、内容包导入导出、设置、统计
│  ├─ main.dart         入口（含错误边界与 Android 导入 Intent）
│  └─ theme.dart        纸感配色
├─ assets/
│  ├─ content/          35 篇课文 JSON + index.json
│  └─ training/         词义训练题库（熟词生义/一词多义/古今异义）
├─ test/                Flutter 测试（内容、SRS、老师端、导入、训练等）
├─ tool/                预览截图（golden）与辅助脚本
├─ android/             Android 工程
└─ windows/             Windows 工程
```

| 项目结构.md | 本文件 |

## content/ 与 tools/

- `content/完整内容规范.md`、`content/新增篇目规范.md`、`content/词义训练规范.md`：内容生产规范。
- `tools/validate_content.py`：校验 35 篇 JSON（字段、id、token 顺序、译文/释义）。
- `tools/pack_content.py`：生成 `.wyc` 内容包（manifest + SHA-256）。

## 构建与校验

```bash
cd app
flutter pub get
flutter test
flutter build apk --release
flutter build windows --debug
```

```bash
python tools/validate_content.py
python tools/pack_content.py
```
