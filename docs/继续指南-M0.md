## 五、已知问题与对应解法

| 现象 | 原因 | 解法 |
|---|---|---|
| flutter 命令无限重试 “pub upgrade” | DSH 沙箱禁止 Dart 创建子进程 | 必须用**完整访问权限（danger-full-access）**执行 flutter 命令 |
| `CreateFile failed 5` / 拒绝访问 | 默认用户目录 `C:\Users\...\AppData` 被沙箱拒绝 | 先 `. 'D:\dev\env.ps1'` 重定向 |
| git 报 `dubious ownership` | D 盘文件系统不记录所有者 | 已配置 `safe.directory`，无需再处理 |
| Gradle 下载超时 | services.gradle.org 被墙 | 已换腾讯云镜像 |
| Maven 依赖超时 | google()/mavenCentral() 被墙 | 已加阿里云镜像 |
| Chrome 缺失 | 未装 Chrome | 不影响 Android/Windows，仅影响 flutter web |
| Android 构建卡住 | 首次下载 + daemon 中途退出 | 直接重跑；如再卡：设 `$env:GRADLE_OPTS='-Dorg.gradle.daemon=false'`，或删 `D:\dev\gradle\daemon` 后重试 |
| 中文路径 | AGP 默认拒绝非 ASCII 路径 | 已加 `android.overridePathCheck=true`，实测通过 |
| `kotlin {}` 报找不到插件 | Gradle 脚本带了 UTF-8 BOM | 用无 BOM 方式重写 `*.gradle.kts` / properties |
| 缺 NDK 28.2 | Flutter 3.47 强制要求 | 已安装 `ndk/28.2.13676358`（2.1 GB） |
