## 四、已知的环境限制（重要）

1. **DSH 沙箱禁止 Dart 创建子进程**（会报 `ProcessException 拒绝访问`）。
   Flutter 本身就是 Dart 程序，因此 `flutter` 的所有命令必须用**完整访问权限（danger-full-access）**执行，否则会在启动 git 时失败并无限重试。
2. **默认用户目录不可写**：`C:\Users\...\AppData` 被沙箱拒绝，所以必须用 `env.ps1` 把 HOME/APPDATA/LOCALAPPDATA/TEMP 重定向到 D 盘。
3. **中文路径**：工程位于 `D:\学习\DScoding项目测试\wenyan\app`，Windows 版已验证可编译；Android 版待验证。
4. **D 盘不记录文件所有者**：git 会报 `dubious ownership`，已通过 `git config --global --add safe.directory '*'` 解决（写入 `D:\dev\home\.gitconfig`）。
5. **GitHub 直连不稳**，下载统一走国内镜像（Flutter 镜像、清华镜像、Google 官方源在国内可直连）。
6. **中文路径**：Android 构建需要在 `app/android/gradle.properties` 加 `android.overridePathCheck=true`（已加）。
7. **BOM 坑**：Gradle/Kotlin 脚本（`*.gradle.kts`、`*.properties`）不能带 UTF-8 BOM，否则插件块解析失败，报 `kotlin {}` 找不到插件。改这些文件要用无 BOM 方式写入。
8. **NDK 是强制的**：Flutter 3.47 即使纯 Dart 应用也要求 NDK 28.2.13676358，缺失时报 `Android sdkmanager did not install NDK 28.2.13676358`。
