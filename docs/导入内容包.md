# 导入内容包（.wyc）

## 老师端导入

1. 打开老师端 → 左侧「导入」
2. 把 `.wyc` 文件放到显示的文件夹（Windows 是 `%APPDATA%\wenyan\imports`）
3. 点「重新扫描」→ 列表出现文件 → 点「导入」
4. 成功后回到「篇目」，点右上角刷新，新篇目/修改就会出现

## 学生端导入

- 「我」→「导入内容包」→ **从手机选择 .wyc 文件**（系统文件选择器）
- 微信里先把 `.wyc` 保存到手机：文件 → 右上角「…」→ 保存/用其他应用打开
- 导入后回首页点右上角**刷新**

> 安卓已改为系统文件选择器，不再需要放进应用私有目录。

## 规则

- 导入是**叠加**：同 `id` 的篇目覆盖内置/之前导入的版本，新 `id` 追加到列表尾部
- 导入前会校验 manifest 与 **SHA-256**，损坏或被篡改的包会被拒绝
- 老师端的本地修改（`teacher_edits.json`）依然叠加在导入内容之上
- 「已导入」区域可以单个移除；移除后回首页刷新即恢复

## 演示包

`release/wenyan-demo-extra.wyc` 是一个演示包：新增《论语十二章（选）》2 句，校验和 `sha256:c441fc5e...`。

我已经把它复制到 `%APPDATA%\wenyan\imports\`，你打开老师端「导入」应该能直接看到它。

## 验证流程

1. 老师端 → 导入 → 看到 `wenyan-demo-extra.wyc` → 导入
2. 回「篇目」刷新 → 列表多出《论语十二章（选）》
3. 打开《论语》→ 编辑「说」的释义 → 预览
4. 导出新内容包 → 再导入 → 观察覆盖行为
